# مدیریت انرژی ساختمان — نسخه موبایل / iOS (وب‌اپ)

این نسخه‌ی وب (PWA - Progressive Web App) همان قابلیت‌های اصلی نرم‌افزار
دسکتاپ ویندوزی (پروژه، پوسته ساختمان، تجهیزات، شاخص انرژی، ردیابی
سه‌مرحله‌ای، بازرسی مبحث ۲۲، اتصال IBMS و گزارش) را در قالب یک صفحه‌ی وب
موبایل‌محور، مناسب آیفون/آیپد (و هر مرورگر دیگری)، ارائه می‌دهد.

## ⚠️ چرا وب‌اپ به‌جای اپ بومی App Store؟

ساخت یک اپ بومی iOS (Swift/SwiftUI) و انتشار آن در App Store به Mac، Xcode،
حساب Apple Developer Program (۹۹ دلار در سال) و فرآیند تایید اپل نیاز دارد که
هیچ‌کدام در دسترس این محیط توسعه نیست و ارسال نهایی هم فقط با هویت شخص شما
ممکن است. وب‌اپ (PWA) جایگزینی کاملاً واقعی و رایگان است: از طریق Safari باز
می‌شود، با «افزودن به صفحه اصلی» دقیقاً مثل یک اپ نصب‌شده (آیکون اختصاصی،
تمام‌صفحه، بدون نوار آدرس) کار می‌کند و حتی بعد از بار اول، آفلاین هم اجرا
می‌شود.

## نصب روی آیفون/آیپد (چند دقیقه، بدون Xcode یا حساب اپل)

برای اینکه این صفحه از طریق اینترنت در دسترس آیفون شما باشد، باید آن را
میزبانی (Host) کنید. ساده‌ترین و رایگان‌ترین راه، **GitHub Pages** است (اگر
از مراحل قبلی همین پروژه یک حساب گیت‌هاب دارید، از همان استفاده کنید):

1. یک مخزن (Repository) جدید در [github.com](https://github.com) بسازید
   (می‌تواند Public باشد چون این اپ اطلاعات حساسی سمت سرور ندارد؛ تمام داده‌ها
   فقط روی خود گوشی شما در حافظه مرورگر ذخیره می‌شوند).
2. تمام فایل‌های همین پوشه (`energy_app_ios/`) را در آن مخزن آپلود کنید
   («Add file ▸ Upload files»، سپس «Commit changes»).
3. به «Settings ▸ Pages» بروید. زیر «Build and deployment»، گزینه‌ی Source را
   روی «Deploy from a branch» و شاخه (Branch) را روی `main` (پوشه‌ی `/root`)
   تنظیم کنید و «Save» را بزنید.
4. بعد از ۱ تا ۲ دقیقه، یک آدرس به شکل
   `https://<نام‌کاربری‌شما>.github.io/<نام‌مخزن>/` در همان صفحه ظاهر می‌شود.
5. این آدرس را در **Safari** آیفون/آیپد باز کنید.
6. روی دکمه‌ی اشتراک‌گذاری (مربع با فلش رو به بالا) در نوار پایین Safari بزنید
   و «Add to Home Screen» (افزودن به صفحه اصلی) را انتخاب کنید.
7. حالا یک آیکون اختصاصی روی صفحه‌ی اصلی گوشی‌تان دارید؛ با زدن روی آن،
   برنامه تمام‌صفحه (بدون نوار آدرس مرورگر) باز می‌شود.

> 💡 نکته: برای تست سریع روی کامپیوتر خودتان قبل از انتشار، کافی است در همین
> پوشه دستور `python -m http.server 8000` را اجرا کرده و
> `http://localhost:8000` را در مرورگر باز کنید.

## ذخیره‌سازی داده‌ها

تمام اطلاعات پروژه (در تمام تب‌ها) در حافظه‌ی محلی مرورگر
(`localStorage`) روی همان دستگاه ذخیره می‌شود — نیازی به اینترنت برای کار
روزمره با برنامه نیست (فقط بار اول برای بارگذاری صفحه به اینترنت نیاز است؛
پس از آن، به لطف Service Worker، آفلاین هم کار می‌کند). اگر مرورگر یا حافظه‌ی
گوشی پاک شود، اطلاعات از بین می‌رود — برای پشتیبان‌گیری، از تب «گزارش»
خروجی PDF/چاپ بگیرید.

## تولید گزارش (PDF)

از تب «گزارش»، روی «چاپ / ذخیره به‌عنوان PDF» بزنید. سیستم چاپ Safari باز
می‌شود؛ از گزینه‌های پایین صفحه «Export as PDF» یا «ذخیره در Files» را
انتخاب کنید تا فایل PDF گزارش (با متن فارسی صحیح، چون از فونت خود سیستم
iOS استفاده می‌شود) ذخیره شود.

## ساختار پروژه

```
energy_app_ios/
├── index.html          # صفحه اصلی
├── manifest.json        # تنظیمات نصب PWA (آیکون، نام، رنگ)
├── service-worker.js     # کارکرد آفلاین
├── css/style.css         # ظاهر گرافیکی موبایل‌محور
├── js/
│   ├── data.js           # داده‌های مرجع (از climate_data.json تولید شده)
│   ├── calculations.js   # موتور محاسباتی (معادل جاوااسکریپتی calculations.py)
│   └── app.js            # منطق رابط کاربری و تب‌ها
└── icons/                # آیکون‌های برنامه (تولیدشده با make_logo.py نسخه دسکتاپ)
```

## هم‌گام نگه‌داشتن با نسخه دسکتاپ

اگر در `climate_data.json` نسخه دسکتاپ تغییری دادید (مثلاً شهر یا برند
جدید اضافه کردید)، برای اعمال همان تغییر در این نسخه، فایل `js/data.js` را
دوباره از روی JSON بسازید:

```python
import json
with open("../energy_app/data/climate_data.json", encoding="utf-8") as f:
    climate = json.load(f)
with open("../energy_app/data/checklist_mabhas22.json", encoding="utf-8") as f:
    checklist = json.load(f)
with open("js/data.js", "w", encoding="utf-8") as f:
    f.write("const CLIMATE_DATA = " + json.dumps(climate, ensure_ascii=False, indent=2) + ";\n\n")
    f.write("const CHECKLIST_DATA = " + json.dumps(checklist, ensure_ascii=False, indent=2) + ";\n")
```

## ⚠️ محدودیت‌های این نسخه نسبت به نسخه دسکتاپ

- منوی «مهندسی» رمزدار و پنل ویرایش ضرایب پیاده‌سازی نشده (برای تغییر ضرایب،
  مستقیماً `js/data.js` را ویرایش کنید).
- دفترچه راهنمای کاربر و منوی «راهنمای کامل» به‌صورت جداگانه در این نسخه
  نیست؛ به‌جای آن همین فایل README را مطالعه کنید.
- اعتبارسنجی ورودی محدود است (فرض بر ورود اعداد/متن معتبر توسط کاربر است).
- اتصال IBMS از مرورگر انجام می‌شود؛ در صورت وجود محدودیت CORS در سرور
  IBMS شما، ممکن است نیاز به تنظیم اضافه در سمت آن سرور باشد.
- تمام داده‌های مرجع (شهرها، ضرایب سوخت، برندها و ...) دقیقاً همان محدودیت‌ها
  و تقریب‌های نسخه دسکتاپ را دارد (به README نسخه دسکتاپ مراجعه کنید).
